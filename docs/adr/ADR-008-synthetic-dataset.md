# ADR-008: 合成企业数据集（Mock-first）

- 状态：Accepted（2026-09-04）

## 决策

v0 不等待、不接入任何真实企业数据。由 `scripts/gen_dataset.py` 生成 "Demo Corporation" 合成企业（规模与对抗性要求见 PRD §27/§28：20+ 人、50+ 供应商、200+ 采购申请、500+ 审批/文档；必含同名人员、同供应商多名称、历史组织变更、权限边界、不完整资料、金额卡阈值例）。Demo 数据与评测数据同源生成（EVALUATION §4）。

## 理由

1. 无客户授权数据前，合成数据是唯一能立刻开工的路径（根目录 Round 1 ADR-001 Mock-first 原则的延续）。
2. 对抗性用例在合成数据中可**刻意构造且可复现**（真实数据做不到）。
3. 私有化演示时，合成数据无泄露风险，可现场展示权限拒绝路径。

## 后果与边界

- 正：评测可回归、演示可控、无合规风险。
- 负：合成分布 ≠ 真实分布（真实脏数据的 resolution/权限复杂度更高）——POC 接入首个客户真实快照时，E1/E2 必须重跑并把差距记入 eval-report；此为已知债务，接受。
