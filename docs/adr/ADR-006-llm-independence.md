# ADR-006: LLM 供应商独立 + 国产开源模型优先适配

- 状态：Accepted（2026-09-04）

## 决策

1. 唯一 LLM 通道：OpenAI 兼容端点，环境变量 `ECE_LLM_BASE_URL / ECE_LLM_API_KEY / ECE_LLM_MODEL`；代码零厂商 SDK、零模型名硬编码。
2. v0 验收基线必须包含一款**本地部署国产开源模型**（Ollama/vLLM 跑 Qwen/DeepSeek），与一个强基线模型在 E6 上对照（EVALUATION §0）。
3. 架构上"规则优先"：确定性判断（比价触发、偏离带、审批链完整性）由纯 Python 规则承担，LLM 只做综合表述与解释——负载分布对开源模型友好。
4. Embedding 同理独立：`ECE_EMBED_PROVIDER=local|api`，默认本地 bge-small-zh-v1.5（512d）；一个部署一个模型，禁止混维。

## 理由

中国市场事实（根目录 RED_TEAM v3 §0.6）：企业普遍不敢用闭源 API，大概率自部署开源模型。LLM 独立（PRD P5）在中国不只是架构洁癖，而是**可售性前提**（私有化、数据不出域、断网可运行——TASKS S6.5 验收）。

## 后果

- 正：同一代码同时服务"本地开源"与"云端强模型"两类部署；评测报告成为销售物料（开源模型可用性证明）。
- 负：开源模型复杂推理弱——由规则优先架构对冲，E6 双模型报告量化残余差距。
